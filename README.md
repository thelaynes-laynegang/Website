# Music Promotion Website Setup Instructions

Welcome to the Music Promotion Website! Follow these steps to set up your local environment.

## Prerequisites
- Ensure you have [Node.js](https://nodejs.org/) installed.
- Install [Git](https://git-scm.com/).

## Setup Steps
1. **Clone the repository**:
   
   ```bash
   git clone https://github.com/thelaynes-laynegang/Website.git
   cd Website
   ```

2. **Install dependencies**:
   
   ```bash
   npm install
   ```

3. **Run the application**:
   
   ```bash
   npm start
   ```

4. Open your browser and navigate to `http://localhost:3000`
